# Contributing to Locus

Thank you for looking. Locus is early, source-available software (FSL-1.1-ALv2, see [LICENSE](LICENSE)),
maintained by one person.

## Issues are welcome

The most useful things you can send:

- **Install problems.** Tell me your operating system, your MCP client (Claude Code, Claude Desktop, Cursor or
  other) and how you installed Locus. Paste the exact error text and the output of `locus doctor`. Please remove
  personal file names and paths before pasting.
- **Wrong or missing answers.** Say what you asked, which file you expected, and which file Locus returned. Do not
  paste private document contents; describe them, or use the demo folder in `tests/fixtures/demo-vault`.
- **Ideas.** One idea per issue. There is no promise to build it, and some ideas will be declined to keep the
  project small.

Security problems: do not open a public issue. Follow [SECURITY.md](SECURITY.md).

Please be kind. This is a one-person project and replies can take a day or two.

## Pull requests are not accepted yet

I am not merging outside code for now. A contributor agreement is being prepared so that your contribution and the
licence of the project are clear for everyone. Until it exists, a pull request will be closed with a thank-you and a
pointer to this page, even if it is good. That is not a judgement of your work. Please do not spend time on a patch yet.

Found a typo or a wrong sentence in the documentation? Open an issue with the correct text and I will make the change.

When the agreement is ready, this page will say so and the README line "Pull requests are not accepted yet" will change.
