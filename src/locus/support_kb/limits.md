### What if my assistant answers without searching my files?
Assistants do not always call Locus on their own. Say "search my files with Locus". See Limits.

- Locus can miss a file or return the wrong passage. Check an answer against the file the result names.
- No text recognition: scans, photos and handwriting are not read.
- The index is readable text, not encrypted. Use disk encryption and keep `~/.locus` out of synced folders.
- No email, calendar or web search. Locus searches the folders you choose.
- claude.ai and ChatGPT are not supported in this release.
- Not a replacement for a full desktop search app.
- Early software: no independent security audit, and what was tested was tested by the project, on one Mac.
- Windows is not verified as supported; see the versions article.
