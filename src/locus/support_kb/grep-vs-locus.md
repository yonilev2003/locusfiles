- **Exact words, a name, an error string, a code symbol:** use grep, ripgrep or your desktop search. They find the text
  you typed and nothing else.
- **A question in your own words, where the file may use different words:** Locus does semantic search, so the
  passage can match the meaning and not only the words. It can also miss, so check the file the result names.
- **Many files at once:** an assistant with Locus can combine results from several files and name each one.

This article makes no speed or quality comparison: none was measured against grep or desktop search on your files
(unverified). Locus is not a replacement for a full desktop search app.
